IIT Patna Hostel Mess Menu
Description:-

This project displays the daily and weekly hostel mess menu for IIT Patna students. It helps students easily check meal details without relying on notice boards.

Features:-

1.Day-wise mess menu

2.Breakfast, Lunch, Snacks, and Dinner details

3.Simple and easy-to-use interface

Technologies Used:-

1.HTML – Structure of the website

2.CSS – Styling and layout

3.JavaScript – Dynamic content and interactions

4.Vercel – Hosting and deployment

How to Run:-

1.Open index.html in a web browser

2.View the mess menu

3.click this url - https://cvr-mess-menu.vercel.app/

4.open the url in browser and go to add to home screen then install

Institution:-

Indian Institute of Technology Patna
